    HOW THIS IS VERIFIED (WITHOUT TRUSTING ANYONE)
    • We download the evidence package (polygon + verdict + measurements) exactly as it was sealed.
    • Your browser computes its keccak256 fingerprint — the same calculation the system made when sealing.
    • That fingerprint is compared with the one recorded on Polygon. Nobody can change the one on Polygon.
    • If both match, the data is exactly what was sealed. If anyone had touched it, they would not match.
